极夜海雀 · 开发历程

从一片雪地开始,一路加到南海北陆、鱼群、鲸鱼。历史版本网页。

v1

初版 · 冰岛雪地场景

极光、雪山、飘雪与昼夜切换;海雀在雪地上走动,点地面撒草料,点海雀让它翻个跟头, 水塘与鱼, 雪地里的水塘不结冰,鱼在里面游动;点鱼会吓得它跳上岸,变成海雀的食物,吃完水塘会自动补新鱼。

加入海洋与浮冰，鲸鱼登场

冰面变为圆形，粗糙海洋建立，新增鲸鱼与极低浮冰。

v3

大改版 · 修复地形渲染（南海北陆） / 点击失效

修了一个背面剔除的底层 bug， 地形从"孤岛环海"改成"北边陆地、南边开阔海"，海岸线做成锯齿状。新增鲸鱼:偶尔浮出水面、点它喷水变小、投喂它会游过来吃掉变大。

v4

地图三倍扩大 + 山脉均匀分布+物理碰撞

世界边界推远并用雾效藏起来,海岸碎冰稀疏化,山脉间距拉开不再拥挤。食物不能扔进山里,海雀走路会绕开山体。

打开这一版 →
v5

鲸鱼放大 3 倍 + 找食范围

鲸鱼模型整体放大 3 倍(下潜深度同步调整,避免露出水面);海雀和鲸鱼都加入了"找食范围"，离食物太远就不会再赶过来。

打开这一版 →
v6

鲸鱼浮水更自然 + 满天极光 + 视角防穿地

鲸鱼浮出水面时改成大半个身子沉在水下、只露出背部和背鳍(之前是整只飘在水面上),胸鳍、尾巴和身体摆动也更有生气;极光从原来一小段弧形扩展成整片天空环绕;镜头加了地面/海面下限,不会再被甩到地底下往上看;水塘改成不规则的自然形状;开场引导文案与可读性也做了微调。

打开这一版 →
v7

鲸鱼跃出水面 + 带娃 / 极夜里海雀睡觉、流星

鲸鱼会不定期跃出水面(breach)或用力拍打尾巴溅起水花;长到最大之后还会带上一只跟着游的小鲸鱼。极夜里海雀闲下来时会趴下睡觉,天亮或被戳一下才会醒;极光在夜里更明亮;夜空偶尔会划过一颗流星。

打开这一版 →
v8

小鲸鱼独立生活 + 流星修复 + 海雀不再挤成一团

淡绿色的小鲸鱼变成独立个体,会自己找食物、吃了会长大,但不会再生下一只;修复了流星只出现在正头顶、镜头根本看不到的问题;多只海雀同时抢食时会在食物周围散开站,不再叠在一起穿模。

打开这一版 →
v9 · 当前版本

休眠火山 + 绿色流星 + 海雀趴着睡

冰原上多了一座大型休眠火山(暂不喷发),和其他山一样有碰撞:海雀走路会绕开,飞行时会自动抬高弧线越过山顶,食物也扔不进去。流星改成一道细细的绿色轨迹,燃尽时会闪一下。修复了海雀睡着后慢慢沉进雪里、醒来又突然冒出来的 bug,现在只是压低身子、低头趴在雪面上。
